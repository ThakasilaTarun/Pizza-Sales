# 🍕 Pizza Sales Analysis Dashboard | SQL & Power BI

## 📌 Project Overview
This project analyzes pizza sales data using **SQL** and **Power BI** to understand sales performance, order trends, and product-level performance. The Power BI report presents key metrics and interactive visuals to help explore the data and identify useful business insights.

## 🎯 Project Objectives
- Measure overall sales performance using key performance indicators (KPIs).
- Understand daily and monthly order trends.
- Compare sales across pizza categories and sizes.
- Identify the best- and worst-performing pizzas by revenue, quantity sold, and total orders.
- Present the analysis in an interactive Power BI dashboard.

## 🛠️ Tools & Technologies
- **SQL** — querying and analyzing sales data.
- **Power BI** — data visualization and interactive reporting.

## 📊 Dashboard Highlights

### 1. Home Dashboard
- Total Revenue
- Average Order Value
- Total Pizzas Sold
- Total Orders
- Average Pizzas Per Order
- Daily and monthly order trends
- Sales distribution by pizza category and size
- Pizza quantity sold by category
- Filters for pizza category, pizza size, and order date

### 2. Best/Worst Sales Dashboard
- Top 5 pizzas by revenue
- Top 5 pizzas by quantity sold
- Top 5 pizzas by total orders
- Bottom 5 pizzas by revenue
- Bottom 5 pizzas by quantity sold
- Bottom 5 pizzas by total orders

## 🔎 Key Business Questions
- Which days and months have the highest number of orders?
- Which pizza categories contribute most to revenue?
- Which pizza sizes contribute most to sales?
- Which pizzas are the best sellers by revenue, quantity, and orders?
- Which pizzas have the lowest performance across these measures?

## 💡 Insights Shown in the Dashboard
- Friday and Saturday have high order volumes.
- July and January show high monthly order volumes in the displayed report.
- The Classic category contributes strongly to total sales and orders.
- Large pizzas contribute a significant share of sales.
- The dashboard highlights best- and worst-selling pizzas across multiple measures.

> These observations are based on the current dashboard view and may change when filters are applied.
